📝 Task Manager Web App

A full-stack task management application built with ASP.NET Core MVC (.NET 8) that enables users to efficiently create, manage, and track their tasks. The application supports full CRUD functionality, allowing users to add, view, update, and delete tasks with ease.

Each task includes a name, description, and due date, with validation in place to ensure accurate and meaningful data entry. The backend is powered by Entity Framework Core, using a code-first approach to design and manage the database.

This project demonstrates my understanding of MVC architecture, model binding, form handling, and server-side validation, as well as my ability to integrate a database into a web application. I also incorporated Font Awesome to enhance the user interface with clean and intuitive visuals.

🌦️ Weather Web App

A simple and responsive weather application built with HTML, CSS and JavaScript that allows users to search for any city and view real-time weather information about the temperature, cloud cover, humidity and wind speed for the specified city for that date.

The application was built using HTML, CSS, and JavaScript, and integrates with the OpenWeatherMap API to fetch live data. It demonstrates my ability to work with external APIs, handle asynchronous JavaScript using 'fetch()', and dynamically update the user interface based on user input.

Through this project, I focused on strengthening my understanding of core JavaScript concepts such as DOM manipulation, event handling, and working with JSON data. I also aimed to create a clean, responsive, and user-friendly interface using Font Awesome. This project reflects my growing confidence in building functional web applications and my ability to connect front-end interfaces with real-world data sources.
